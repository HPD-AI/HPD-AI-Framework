# HPD BASE Studio

The trusted Svelte 5 presentation contribution for BASE's graph-owned Studio module.
It exports the fixed L52 module descriptor and activation ABI; authentication,
transport, routing authority, and disclosed operation contracts remain shell-owned.

`dist/base.js` is the checked-in, content-addressed production asset consumed by the
`HPD.Base.Studio` NuGet package. Consumer application builds do not run Node or Vite.
