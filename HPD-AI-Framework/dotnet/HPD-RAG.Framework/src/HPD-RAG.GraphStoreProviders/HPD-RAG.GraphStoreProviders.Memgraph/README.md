# HPD-RAG.GraphStoreProviders.Memgraph

Memgraph graph store provider for HPD-RAG. Uses the Bolt protocol via the Neo4j .NET driver.

## Install

```bash
dotnet add package HPD-RAG.GraphStoreProviders.Memgraph
```

## Use When

Use this package when you need the Memgraph graph store provider for HPD RAG.
