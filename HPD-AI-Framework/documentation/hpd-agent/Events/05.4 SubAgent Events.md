# SubAgent Events

> Filtering live events from nested agents without duplicating durable branch history.

You only need this page if your app uses SubAgents or multi-agent workflows. Single-agent applications can usually ignore `AgentEvent.Metadata`.

## Live Events vs Branch History

SubAgents are branch-native:

```text
Parent branch:
  parent messages
  parent tool call
  SubAgent result
  parent final answer

SubAgent branch:
  child prompt
  child messages
  child tool calls/results
  child final answer
```

During a run, SubAgent events are still bubbled to the parent live stream so UIs can show progress. Those live events carry `AgentEvent.Metadata`, which identifies the agent that emitted the event.

Durable branch relationships live on `Branch.Metadata` and branch events with `branchMetadata`. Do not use live `AgentEvent.Metadata` as persisted branch metadata.

## AgentEvent.Metadata

`AgentEvent.Metadata` identifies live event ownership:

```csharp
public record AgentMetadata
{
    public required string AgentName { get; init; }
    public required string AgentId { get; init; }
    public string? ParentAgentId { get; init; }
    public IReadOnlyList<string> AgentChain { get; init; }
    public int Depth { get; init; }
    public bool IsSubAgent => Depth > 0;
}
```

Depth values show the live nesting level:

```text
Root Agent        Depth = 0
  SubAgent        Depth = 1
    SubAgent      Depth = 2
```

## Show Only Parent Output

Most chat UIs should hide internal SubAgent text by default:

```csharp
agent.On<TextDeltaEvent>(evt =>
{
    if (evt.Metadata?.IsSubAgent == true)
        return ValueTask.CompletedTask;

    Console.Write(evt.Text);
    return ValueTask.CompletedTask;
});
```

## Show SubAgent Progress

If you want to show live child work inline, use the metadata to label it:

```csharp
agent.On<TextDeltaEvent>(evt =>
{
    var meta = evt.Metadata;

    if (meta?.IsSubAgent == true)
        Console.Write($"[{meta.AgentName}] {evt.Text}");
    else
        Console.Write(evt.Text);

    return ValueTask.CompletedTask;
});
```

## Group Events By Agent

```csharp
var byAgent = new Dictionary<string, List<AgentEvent>>();

agent.On<AgentEvent>(evt =>
{
    var agentId = evt.Metadata?.AgentId ?? "root";

    if (!byAgent.TryGetValue(agentId, out var events))
    {
        events = new List<AgentEvent>();
        byAgent[agentId] = events;
    }

    events.Add(evt);
    return ValueTask.CompletedTask;
});
```

## Branch Metadata For Hydration

For persisted UI state, follow the branch metadata link instead of copying child events into the parent branch.

SubAgent-created branches include metadata similar to:

```json
{
  "kind": "subagent",
  "subAgentName": "CodeReviewer",
  "parentSessionId": "session-123",
  "parentBranchId": "main",
  "parentToolCallId": "call-456",
  "subAgentRunId": "run-789",
  "visibility": "hidden"
}
```

That lets host apps and clients:

- hide SubAgent branches from normal branch navigation by default
- show SubAgent work under the parent tool call
- open the child branch for inspection
- hydrate the child branch independently after reconnect

## SSE Route Scoping

When a client subscribes to the parent branch event stream, HPD-Agent can include live events from linked SubAgent child branches. A child event is allowed through only when its branch metadata says:

```json
{
  "kind": "subagent",
  "parentSessionId": "observed-session",
  "parentBranchId": "observed-branch"
}
```

Unrelated branch events are rejected. This gives the UI live SubAgent progress without polluting the parent branch's durable event history.

## Safe Access Pattern

```csharp
var isSubAgent = evt.Metadata?.IsSubAgent ?? false;
var agentName = evt.Metadata?.AgentName ?? "Root";
var depth = evt.Metadata?.Depth ?? 0;
```
