# HPD-RAG.EmbeddingProviders.OnnxRuntime

ONNX Runtime embedding provider for HPD-RAG. Runs embedding models locally via Microsoft.Extensions.AI.Onnx.

## Install

```bash
dotnet add package HPD-RAG.EmbeddingProviders.OnnxRuntime
```

## Use When

Use this package when you need the OnnxRuntime embedding provider for HPD RAG.
