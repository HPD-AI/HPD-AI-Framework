# HPD-RAG.RerankerProviders.OnnxRuntime

Local ONNX cross-encoder reranker provider for HPD-RAG via Microsoft.ML.OnnxRuntime.

## Install

```bash
dotnet add package HPD-RAG.RerankerProviders.OnnxRuntime
```

## Use When

Use this package when you need the OnnxRuntime reranker provider for HPD RAG.
