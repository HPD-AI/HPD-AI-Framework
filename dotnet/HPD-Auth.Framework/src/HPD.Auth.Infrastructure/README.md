# HPD-Auth-Infrastructure

HPD Base-backed Identity, session, refresh-token, audit, and Data Protection adapters
for HPD Auth. The package contains no provider SQL, migrations, or ORM escape hatch;
the host installs the closed `AuthBaseModule` into its finalized Base graph.

## Install

```bash
dotnet add package HPD-Auth-Infrastructure
```

## Use When

Use this package when you need this HPD Auth capability.
